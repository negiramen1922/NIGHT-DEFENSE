# 魔物の仕様（2026-11-13・まとめ）

数字は整数・%で書く（小数を使わない）。「1秒の攻撃力」＝1回の攻撃 ÷ 攻撃の間隔。速さは兵士（弓兵32・兵士36）と比べる目安。

- **装甲**：受けるダメージを減らす（装甲無視はなくした）
- **建物へ**：施設・壁に与えるダメージの倍率（壊し役はトロール）
- **兵士へ**：部隊に与えるダメージの倍率
