# 魔物の仕様（2026-11-13・まとめ）

数字は整数・%で書く（小数を使わない）。「1秒の攻撃力」＝1回の攻撃 ÷ 攻撃の間隔。速さは兵士（弓兵32・兵士36）と比べる目安。

- **装甲**：受けるダメージを減らす（装甲無視はなくした）
- **建物へ**：施設・壁に与えるダメージの倍率（壊し役はトロール）
- **兵士へ**：部隊に与えるダメージの倍率

## ボスの技の合図

ゴブリンキングと蠢く木陰は、技を使うとき（号令・森の抱擁（根の攻撃）の前ぶれの2秒）は**立ち止まる**（動かず攻撃もしない）。頭の上に「！ 王の号令！」「！ 森の抱擁（根の攻撃）！」、足元に光る輪が出る

## モウラーの動き

地面に潜って施設や部隊のそばまで近づき、近くで顔を出して攻撃する。潜っている間は攻撃されない。柵や壁も下をくぐる
