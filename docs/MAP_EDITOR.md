# 地図の道具（マップデザインツール）

2026-11-25 作成。グレイヴェル平原の地図を、タイルを塗って描くための道具です。

- 場所：`proto/mapedit.html`（公開ページでは https://negiramen1922.github.io/NIGHT-DEFENSE/proto/mapedit.html ）。試作版のタイトルの下の段の「地図の道具」からも開ける。
- 1マス＝ゲームの 3×3 マス（地図を作るときの大きさ。横96・縦78）。

## できること
- 地形を塗る：草地・丘（石）・森（木）・岩（通れない）・水（川・湖。通れない）・浅瀬（渡れる）。筆（大きさ 1・2・3・5・8）・塗りつぶし・スポイト。
- 資源の印：鉄鉱脈・龍脈の泉（足す／消す）。
- 置くもの：魔物の巣（4つまで。攻めてくる順番 1〜4、名前、方角の文字）・城の候補（3つまで。名前、食料の多さ 1〜3）。「動かす」でつまんで動かす、Delete で消す。
- 確かめる：選んだ城の候補へ、巣から攻めてくる道（ゲームと同じ考え：岩と水は通れない・斜めは1.4倍）。候補のまわり12マスの森・石・鉄・泉・水の数と、各巣からの道のり。行けない巣などのチェック。
- 戻す・やり直す（Ctrl+Z・Ctrl+Y）。描いている途中はブラウザに自動保存（`nd_mapedit_f`）。
- 書き出す：JSON ファイル（`{v:1,map:'f',w,h,t:[行の文字列],ore,oil,hives,sites}`。地形の文字は `.`草地 `h`丘 `f`森 `r`岩 `w`水 `d`浅瀬）。
- ゲームで試す：このブラウザの `nd_map_f` に入れて、試作版を開く。試作版はこれがあると、グレイヴェル平原をこの地図で作る（`customMapF()`・`genCustomF()`・城の候補は `sitesF()`）。「ゲームでの使用をやめる」でもとに戻る。

## 本当の地図にするには
書き出したファイルを作者（Claude）に渡す → `genFantasy()` の代わりにその地図を組み込む（まだしていない）。
