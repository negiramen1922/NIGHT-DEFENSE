# ナイトディフェンス 防衛施設・壁・罠の絵の依頼書（デザイン引き継ぎ用）

2026-11-13 作成。ランクⅠ〜Ⅶの防衛施設・壁・罠を決め直したので、新しく要る絵をまとめた依頼書です。この1枚だけで作業できるようにしてあります。絵の決まり（縁取り・影・コマ数）と材料の色は、これまでの依頼書 `docs/ART_BRIEF.md` と同じです。

> `docs/ART_BRIEF.md` の「4-5. 本編の建物」「4-6. 罠」のうち、防衛施設・壁・罠の部分は**この資料が新しい形**です（魔術の対空塔・大魔導砲・足かせ罠・油の罠・丸太の罠・槍衾・網の罠・大爆弾・結晶爆弾はやめました）。

## 1. ゲームの説明（短く）

- ブラウザで遊ぶ、ドット絵の街づくり＋防衛ゲーム（ダークファンタジー）。夜になるとアビス（地の裂け目）から魔物の大群が攻めてくる。柵・壁・防衛施設・兵士で守る。
- 城のレベル（Lv1〜7）で「ランクⅠ〜Ⅶ」が開き、材料が **鉄 → 鋼 → 合金 → 魔金属 → 聖銀（ミスリル） → 竜晶** と良くなっていく。
- 画面は暗めの夜が基本。明かりの周りだけが明るい。人間側は青・銀・金。
- **名前・見た目は西洋ファンタジー**。和風のものにはしない。

## 2. 絵の決まり（短く）

| 項目 | 決まり |
|---|---|
| 地図の1マス | 14px |
| 大きさ | 1×1マス＝14px（拡大して表示）、2×2マス＝28px、3×3マス＝42px |
| 防衛兵器（撃つもの） | **8方向**（右・右下・下・左下・左・左上・上・右上）＋**撃つ6コマ** |
| 塔・動かない施設 | 待機4コマ（光・炎のゆらぎなど）＋撃つ（光る）4コマ |
| 壁 | つながり方16通り（上・右・下・左のとなりの有無） |
| 罠 | 1マス（14px）。置いた姿1コマ＋発動の効果6コマ |
| 輪郭 | 濃い紫がかった黒（`#1c1824`）の1px の縁取り |

**材料の色**：鉄＝灰 `#9aa0a6`、鋼＝青みの銀 `#b9d3ec`、合金＝黒い鋼に金の縁 `#3a3d4a`、魔金属＝紫 `#a774ec`（鎧などは抑えた紫がかった鉄色 `#8c86a6`）、聖銀（ミスリル）＝白く光る `#f6faff`、竜晶＝赤い結晶 `#e05a4e`、エーテル＝青白い光 `#62c6d9`
