# 桜井流の原則で見た NIGHT DEFENSE の改善案（2026-11-15）

参考：[kociden/sakurai-skill](https://github.com/kociden/sakurai-skill)（YouTube「桜井政博のゲーム作るには」全257本の字幕から作った、ゲーム制作の原則の Agent Skill。非公式のファンメイド・AI による要約）。
`#番号` はそのスキルの動画の通し番号、「○章」はスキルの `SKILL.md` の章。

> スキル本体はライセンスの表記がないので、このリポジトリには写していない。使うときは各自の環境に入れる：
> ```
> git clone https://github.com/kociden/sakurai-skill.git
> cp -r sakurai-skill/skills/sakurai ~/.claude/skills/
> ```
> Claude Code で「桜井さんならどうする？」「このゲームの手応えをレビューして」と頼むと読み込まれる。

原則は大作・アクション寄りの経験から来ているので、そのまま当てはめず、狙い（遊ぶ人を楽しませる）から読み替えている。

## このゲームの面白さの核（一言で）

**昼に「生産を広げる（欲張る）」ほど、夜に「守る範囲と弱点が増える」。そのリスクとリターンの釣り合いを、押し寄せる大群でギュッと試され、しのいでパッと解消する。**（1章・#006・#009）

改良はこの核を太くするか、邪魔なものを減らすかで考える。

---

## 優先度：高（テストプレイヤーの声と直結）

### 1. 第6襲撃あたりで「詰む」のを防ぐ（2章・#211・#254）
- 今：負けたら「最初から」しかない。矢が尽きると防衛がまるごと止まり、そのまま陥落する（1.4.2 の消費1.3倍で起きた）。
- 原則：詰んでクリア不能が最悪。開発者は慣れているので「思ったより下げる」くらいで。リトライは迅速に。
- 案：
  - **「前の朝からやり直す」**を負けの画面に（セーブを朝ごとに1つ残す）。やられてから再開までを短く。
  - 連続で負けたら、屈辱感のない形で「次の襲撃を少し小さくする」提案（例：王都の援軍が来る、という物語の形にする）。
  - **矢が尽きそうなとき、夜の前にはっきり警告**（今の `econWarnings` を、「夜へ」ボタンの隣に赤い札で出す）。
  - 第1〜10襲撃の敵の数を、開発者ではなく初めての人に合わせて一段下げる（ハンデをつけて自分で試す：防衛施設を半分にして通す）。

### 2. 「目の前に吊るす」ご褒美を増やす（3章・#009）
- 今：魔核・研究・城の段が報酬だが、「あと少しで何が手に入るか」が見えにくい。
- 案：上の帯か街タブに**「次の目標」を1つだけ**出す（例：「城Lv3まで：石材 あと120」「研究『投石機』まで：あと2ターン」）。
- 案：襲撃をしのいだ報告画面で、**今夜良かったこと**を褒める（「城壁が一度も破られなかった」「バリスタ3基で120体」）。数字を現実の尺度に置き換えて見せる（「守った住民 240人」）。

### 3. 遅さを削る（4章）
- 今：夜の報告・朝の報告・確認の画面がターンごとに挟まる。襲撃は倍速があるが、最初は×1。
- 案：報告は**画面の端に小さく出して、タップで詳しく**（全画面で止めない）。「次から表示しない」を各報告に。
- 案：襲撃の速度（×1/×2/×3）を**前回の速度で始める**。
- 案：「実際に操作している時間」の割合を、街の記録で測って見直す。

## 優先度：中（手応え・音）

### 4. 撃った・当たった・壊れた手応え（5章・7章・#effects）
- 案：大きな敵を倒したとき・城壁が壊れたときに、**小さな画面振動とヒットストップ（2〜4コマ止める）**。小さな敵には入れない（うるさくなるので強さに比例）。
- 案：爆発は「閃光 → 爆炎 → 黒煙 → 収束」の段を踏む（今は円が広がるだけのものがある）。
- 案：ヒットマークに暗い縁取りを入れて、明るい草地でも見えるように。

### 5. 効果音の優先順位（10章・#sound）
- 今：大群のときは矢・撃破・ヒットが重なって、大事な音（城壁が壊れた・英雄が倒れた・第二波接近）が埋もれる。
- 案：優先順位を決めて、**大事な音が鳴る間は小さい音を下げる**。
  - 順位の目安：襲撃の知らせ・陥落 ＞ 英雄の戦死 ＞ 施設の破壊 ＞ 大きな敵の撃破 ＞ 範囲攻撃 ＞ 発射 ＞ 小さな敵の撃破 ＞ 建設
- 案：ヒット音は「アタック強め、残響ほどほど」。ラボで選んだ案をこの基準で聞き直す。

### 6. 範囲攻撃の調整は「別の軸」で（1章・#245）
- 1.4.1 で範囲攻撃を「爆心から離れるほど弱く（端40%）」した。これは**強みを一律に削る直し方**で、原則（長所を伸ばしたら短所も伸ばす・威力は残して別の軸で）とは逆向き。
- 案：威力（範囲・端のダメージ）は元に近づけて、代わりに**弾の消費・最低射程・発射間隔・味方への誤射**など別の軸で釣り合わせる。投石機は「群れに強いが、近づかれると撃てない」とはっきり尖らせる。

### 7. 相性をはっきり、極端に（#228）
- 今：盾持ちオーガ（正面の矢を防ぐ）、トレント（火に弱い）など相性はあるが、遊んでいて気づきにくい。
- 案：敵が出る夜の前の「敵情予測」で、**「今夜はトレント：火の攻撃が2倍効く」**のように一言で相性を出す。
- 案：相性は遠慮せず極端に（効く攻撃は2〜3倍、効かない攻撃は半分以下）。はまったときの気持ちよさを優先する。

## 優先度：中（導入）

### 8. 最初の3分で「夜の大群」を見せる（4章・#planning）
- 今：最初の襲撃まで10ターンの準備があり、初心者タスクで建設を順に覚える。面白さの核（押し寄せる大群をしのぐ）に出会うまで長い。
- 案：最初の数ターン目に**小さな「夜の偵察隊」**（10体ほど）を来させ、すぐに防衛の手応えを体験させる。
- 案：初心者タスクは「本編の形」のまま、説明文を短く（1行）。

---

## 優先度：低（仕組み）

### 9. 調整の数値を外に出す（11章）
- 今：敵の数・費用・生産量はコードの中に散らばっている（`genWave`・`B[...]`・`TECH_MAT` など）。
- 案：**調整用の数値を1か所の表（`BAL`）に集めて**、試作版のラボのような画面で「その場で変えて試す」。試行回数が調整の深さを決める。
- 済み：街の記録（1.5）で、施設の数・生産量・資源の推移を表計算に出せるようになった。調整の資料として使う。

### 10. 宣伝（13章）
- 済み：宣伝動画は冒頭からゲーム画面（昼と夜の街）を見せている。
- 案：ストアやトップページの最初の画像も、ロゴではなく**大群をしのいでいるゲーム画面**に。タイトルの略称（4文字）も決める（例：「ナイディフェ」→「ナイデフ」）。

## 進め方の提案

1. まず **1（詰み防止）と 2（目の前のご褒美）** をやる。テストプレイヤーの「第6襲撃で負ける」に直接効く。
2. 次に **5（効果音の優先順位）と 4（手応え）**。ラボで聴き比べ・見比べながら。
3. **6（範囲攻撃）** は、街の記録の数字を見ながら、元の強さに戻すか決める。
