## 1. 変わったこと（短く）

- 魔法のランクⅤの素材は「エーテル金属」ではなく、**「月光石」**になりました。
  - エーテルを染み込ませた、**水色に光る石**です。金属ではありません。
  - **夜のあいだだけ**、石材とエーテルから作られます（昼は作らない）。
  - 素材のアイコンは、こちらで仮に作った「水色の三日月の形の石」を使っています。
  - その1で描いてもらった「エーテル金属の段」（水色の大弩・門・壁・道具など）は、そのまま**月光石の段**として使っています。
- 月光石は錬金術とは関係がなくなったので、その1の**錬金工房の絵は、魔法の兵を作る施設**として使うことにしました。
- そのかわり、**月光石を作る施設**と、**工業の兵を作る施設**の絵が新しく要ります。

## 2. 頼みたい絵

### 2-1. 月光の祭壇（魔法・ランクⅤ・優先度 A）

| 項目 | 内容 |
|---|---|
| 大きさ | 42px（3×3マス） |
| 役割 | 夜のあいだに月の光を集めて、石材とエーテルから**月光石**を作る。昼は何もしない |
| コマ | **昼**：待機4コマ（静か。石が少し光る程度）／**夜**：待機4コマ（月の光が細い筋で降りてきて、祭壇の上の石が水色に強く光る） |
| 見た目 | 石を円く並べた祭壇。真ん中の台の上に、**水色の三日月の形の石**が浮かんでいる。台のまわりに、まだ光っていない灰色の石材が積んである |
| 色 | 石は灰色。光は月光石の水色 `#7fd8f5`、明るい所 `#c8f4fb` |
| 名前 | 仮の名前です（変わることがあります） |

### 2-2. 蒸気の訓練場（工業・ランクⅣ・優先度 A）

| 項目 | 内容 |
|---|---|
| 大きさ | 42px（3×3マス） |
| 役割 | **工業の兵**（銃兵・砲兵・狙撃兵・蒸気機兵・蒸気戦車・銃士の気球・爆撃飛行船）を作る・訓練する施設。魔法の錬金工房と対になる |
| コマ | 待機4コマ（煙突の煙、歯車が回る、蒸気が吹き出す） |
| 見た目 | スチームパンクの兵器工場と訓練場。煉瓦の建物に大きな真鍮の歯車と管、煙突。建物の前に射撃の的（木の人形）と、組み立て途中の蒸気機兵の脚や大砲の車輪 |
| 色 | 煉瓦の赤茶、黒鉄の灰黒 `#4a4a56`、真鍮 `#c89a4a`、蒸気の白 |
| 名前 | 仮の名前です |

### 2-3. 大きな厩舎（共通・馬小屋の上の段・優先度 B）

施設が増えすぎないように、**竜舎とグリフォンの厩舎をやめて、馬小屋のアップグレードで竜騎兵とグリフォン騎兵を育てられるように**する予定です（研究で解禁）。

| 項目 | 内容 |
|---|---|
| 大きさ | 28px（2×2マス。今の馬小屋と同じ） |
| 役割 | 馬小屋の上の段。研究すると、ここで竜騎兵とグリフォン騎兵も育てられる |
| コマ | 待機4コマ（旗がはためく、止まり木の上のグリフォンが羽を動かす） |
| 見た目 | 今の馬小屋を大きく高くした厩舎。屋根の上に大きな止まり木、横に竜が入れる高い門。干し草と鞍 |
| 名前 | 仮の名前です |
