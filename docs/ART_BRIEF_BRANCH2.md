## 1. 変わったこと（短く）

- 魔法のランクⅤの素材は「エーテル金属」ではなく、**「月光石」**になりました。
  - エーテルを染み込ませた、**水色に光る石**です。金属ではありません。
  - **夜のあいだだけ**、石材とエーテルから作られます（昼は作らない）。
  - 素材のアイコンは、こちらで仮に作った「水色の三日月の形の石」を使っています。
  - その1で描いてもらった「エーテル金属の段」（水色の大弩・門・壁・道具など）は、そのまま**月光石の段**として使っています。
- 兵の施設を「人を育てる所」と「作るもの（兵器）を作る所」に分けました。

| | 人を育てる | 作るもの（兵器）を作る |
|---|---|---|
| 工業 | **兵舎**（工業の段）：銃兵・砲兵・狙撃兵 | **蒸気の工場**（新しい）：蒸気機兵・蒸気戦車・銃士の気球・爆撃飛行船 |
| 魔法 | **兵舎**（魔法の段）：魔術師・空の魔術師 | **錬金工房**（その1で描いてもらった絵）：エーテルゴーレム・巨大ゴーレム・空飛ぶクジラ |

- **魔導院は建物としてなくして、兵舎にまとめます。** 兵舎はランクⅣから、工業か魔法かで見た目が変わります。
- 月光石を作る施設と、竜騎兵・グリフォンを育てる馬小屋の上の段も、新しく要ります。

## 2. 頼みたい絵

### 2-1. 月光の祭壇（魔法・ランクⅤ・優先度 A）

| 項目 | 内容 |
|---|---|
| 大きさ | 42px（3×3マス） |
| 役割 | 夜のあいだに月の光を集めて、石材とエーテルから**月光石**を作る。昼は何もしない |
| コマ | **昼**：待機4コマ（静か。石が少し光る程度）／**夜**：待機4コマ（月の光が細い筋で降りてきて、祭壇の上の石が水色に強く光る） |
| 見た目 | 石を円く並べた祭壇。真ん中の台の上に、**水色の三日月の形の石**が浮かんでいる。台のまわりに、まだ光っていない灰色の石材が積んである |
| 色 | 石は灰色。光は月光石の水色 `#7fd8f5`、明るい所 `#c8f4fb` |
| 名前 | 仮の名前です（変わることがあります） |

### 2-2. 蒸気の工場（工業・ランクⅤ・優先度 A）

| 項目 | 内容 |
|---|---|
| 大きさ | 42px（3×3マス） |

### 2-3. 兵舎の段の描き直しと、工業・魔法の段（優先度 A）

兵舎は 2×2マス（28px）のまま、段が上がるごとに見た目が変わります。今の絵は **1段目（兵舎）から2段目（石の兵舎）への変わり方が不自然**なので、2段目を描き直してください（参考：`docs/art/branch2_ref/barracks_now.png`。左から 兵舎・石の兵舎・大兵舎）。

**今の2段目の気になるところ**
- 1段目と形・色がまったく違い、同じ建物が強くなったように見えない（緑の屋根 → 赤い屋根、木の壁 → 真っ白な箱）
- 右側に、何か分からない黒い塔と黄色い四角がある
- 1段目にあった**青い旗**と**訓練用の人形**がなくなり、3段目でまた出てくる

**段の並び**

| 段 | ランク | 名前 | 頼みたいこと |
|---|---|---|---|
| 1 | Ⅰ | 兵舎 | 今のまま（木の壁・緑の屋根・青い旗・訓練用の人形） |
| 2 | Ⅱ | 石の兵舎 | **描き直し**。1段目と同じ形・同じ並び（左に旗、右に人形）のまま、壁を石積みに、屋根を少し大きく。人形に鉄の兜を付ける程度。屋根の色は1段目と3段目の間でつながる色に |
| 3 | Ⅳ（工業） | 蒸気の兵舎 | **新しく**。2段目を土台に、黒鉄の補強と真鍮の管、小さな煙突。人形は銃の射撃の的に |
| 3 | Ⅳ（魔法） | 魔導院 | **新しく 28px で**。2段目を土台に、とんがり屋根の小さな塔と水色の窓の光。人形は魔法の的（光る的）に。今の魔導院（42px）の雰囲気を小さくしたもの |
| 4 | Ⅵ（魔法） | 大魔導院 | **新しく 28px で**。魔導院の塔を高くし、月光石の水色の飾りを足す |

- 1〜4段目を並べたとき、**同じ建物が少しずつ立派になっていく**ように見えるのが大事です。
- 今の「大兵舎」（3段目）は使わなくなります（工業か魔法の段に置き換え）。

### 2-4. 大きな厩舎（共通・馬小屋の上の段・優先度 B）

施設が増えすぎないように、**竜舎とグリフォンの厩舎をやめて、馬小屋のアップグレードで竜騎兵とグリフォン騎兵を育てられるように**する予定です（研究で解禁）。

| 項目 | 内容 |
|---|---|
| 大きさ | 28px（2×2マス。今の馬小屋と同じ） |
| 役割 | 馬小屋の上の段。研究すると、ここで竜騎兵とグリフォン騎兵も育てられる |
| コマ | 待機4コマ（旗がはためく、止まり木の上のグリフォンが羽を動かす） |
| 見た目 | 今の馬小屋を大きく高くした厩舎。屋根の上に大きな止まり木、横に竜が入れる高い門。干し草と鞍 |
| 名前 | 仮の名前です |
