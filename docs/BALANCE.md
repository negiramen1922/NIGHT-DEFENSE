# 兵科と魔物の強さの比べ（試作版の数字・2026-11-12）

1部隊対1体で、「部隊が魔物を倒すまでの秒 / 魔物が部隊を全滅させるまでの秒」。左が小さいほど部隊が有利。
- 武器：鉄の武器を100%として 鋼140%・合金190%・魔金属260%・聖銀350%（ランクⅠ鉄・Ⅱ鋼・Ⅲ合金・Ⅴ魔金属・Ⅵ聖銀）
- 鎧（兵士・重装歩兵・騎兵・近衛）：体力が 鉄+10%・鋼+20%・合金+30%・魔金属+45%・聖銀+60%・竜晶+80%（ランクⅠで鉄の鎧の想定）
- 研究：剣術・弓術は城のランクの段まで（1段+15%）、砲兵は砲術+30%
- 弓兵・砲兵・魔術師は遠くから撃つので、実際は表よりずっと有利（近寄られたらこうなる、という数字）
