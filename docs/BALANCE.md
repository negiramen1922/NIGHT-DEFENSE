# 兵科と魔物の強さの比べ（試作版の数字・2026-11-12）

1部隊対1体で、「部隊が魔物を倒すまでの秒 / 魔物が部隊を全滅させるまでの秒」。左が小さいほど部隊が有利。
- 計算の決まり：**装備は「元の値」（整数）を変える**。研究・英雄・中隊などの%は**足し算**してから1回だけ掛ける。受ける被害を減らす効果も全部「耐久」として足し算し、(1＋合計)で割る（掛け合わせない）
- 武器：鉄の武器を100%として 鋼140%・合金190%・魔金属260%・聖銀350%（ランクⅠ鉄・Ⅱ鋼・Ⅲ合金・Ⅴ魔金属・Ⅵ聖銀）
- 鎧（兵士・重装歩兵・騎兵・近衛）：体力 鉄+10%・鋼+20%・合金+30%・魔金属+45%・聖銀+60%・竜晶+80%
- ローブ（弓兵・砲兵・魔術師）：体力 鎖帷子+15%（Ⅱ）・エーテルローブ+30%（Ⅳ）・銀のローブ+50%（Ⅵ）・竜のローブ+75%（Ⅶ）
- 研究：剣術・弓術は城のランクの段まで（1段+15%）、砲兵は砲術+30%。兵士は盾（耐久+25%）、重装歩兵は鎧＋盾＋盾陣（耐久+112%）
- 弓兵・砲兵・魔術師は遠くから撃つので、実際は表よりずっと有利
