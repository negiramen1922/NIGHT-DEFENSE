- 魔物の特徴は**シンプルに**（「硬い」「火に弱い」くらい。要素を盛りすぎない）
- 名前は西洋ファンタジー（和風にしない）

## 新しい魔物の役割（シンプルに）

| 魔物 | 役割 | 効く攻撃 |
|---|---|---|
| トレント | **硬い**。**火に弱い** | ドラゴンブレス・竜騎兵・魔術師の火・メイジの塔 |
| エルダートレント（中ボス） | とても大きくて硬いトレント。火に弱い | 同じ |
| ワーウルフ | ブラッドムーン（21回目から）。**部隊に強い**（レッドキャップの上位） | 防衛施設・罠 |
| マンイーター | 食人植物。根で歩いて近づき、**噛みついて毒にする**（部隊に少しずつダメージ）。**同じ中身で見た目違い**をいくつか（ステージごとに色や花の形を変える） | 遠くから撃つ・早く倒す |
| 巨大コウモリ | 空から群れで来る | 風船爆弾・物見櫓 |
| モウラー | 地面に潜って施設や部隊のそばまで近づき、顔を出して攻撃する（潜っている間は攻撃されない） | 顔を出したところを叩く・近くの守り |
| サラマンダー | 体が燃えていて、触れた木の施設に火がつく | 石の壁・城壁 |
| 盾持ちオーガ | 前からの矢を防ぐ | 曲射（投石機・迫撃砲）・回り込む部隊 |
| 吸血鬼 | 倒した兵を魔物に変える | 聖銀（銀装兵・聖銀の杭）・ミスリルレイ |
| グール | 倒れた魔物の死体を食べて回復する | 早く倒す・範囲攻撃 |
| ストーンゴーレム | とても硬く、壁を一撃で壊す。魔法がよく効く | メイジの塔・テスラ・ハープーン |
