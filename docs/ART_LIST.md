# 新しく必要な絵のリスト（2026-11-11）

これまでの話し合い（攻城戦・ランクⅠ〜Ⅶ・新しい資源・魔物・罠など）で、新しく描く必要が出てきた絵の一覧です。

- **ドット**＝マップや戦場に出る小さな絵（今の `NDSPR` と同じ形式。部隊・魔物は歩き・攻撃のコマ）
- **立ち絵**＝選んだときの大きな絵（情報パネルの上の絵・図鑑）
- **アイコン**＝資源バー・研究・ボタンの小さな絵
- 「代用中」＝今は別の絵で代わりに出しているもの（急がないもの）

優先度：**A**＝試作版ですでに使っている・すぐ要る、**B**＝次に作るもの、**C**＝ランクⅣ以降の新しい中身（中身が決まってから）
