# ナイトディフェンス 絵の依頼書（デザイン引き継ぎ用）

2026-11-12 作成。新しく必要になった建物・アイテム・魔物・兵士の絵をまとめた依頼書です。**それぞれの絵がゲームの中で何のためにあるか（目的・役割）**と、どう見えてほしいかを書いています。この1枚だけで作業できるようにしてあります。

---

## 1. ゲームの説明（短く）

- ブラウザで遊ぶ、ドット絵の街づくり＋防衛ゲーム（ダークファンタジー）。
- 昼に街を育て、夜になるとアビス（地の裂け目）から魔物の大群が攻めてくる。柵・壁・防衛施設・兵士で守る。
- 新しく「**駐留地攻撃（夜襲）**」を作っている：魔物が街の外に作った陣地へ、夜にこちらから攻め込むモード。
- 城のレベル（Lv1〜7）で「ランクⅠ〜Ⅶ」が開き、材料が **鉄 → 鋼 → 合金 → 魔金属 → 聖銀 → 竜晶** と一段ずつ良くなっていく。
- 画面は暗めの夜が基本。明かり（篝火・物見櫓・燃える建物）の周りだけが明るい。

## 2. 絵の決まり（技術）

| 項目 | 決まり |
|---|---|
| 形式 | ドット絵。拡大は整数倍のみ（ぼかさない） |
| 地図の1マス | 14px（柵・壁は1×1＝14px） |
| 建物の大きさ | 2×2マス＝28px、3×3マス＝42px、城は4×4マス＝56px（1コマが正方形） |
| こちらの兵士 | 16px（兵士・重装歩兵は18px）。1部隊は数人が並んで描かれる |
| 魔物 | 16px（大きな魔物も16pxで描き、ゲーム側で拡大する） |
| 弾 | 12〜16px |
| 効果（爆発など） | 16〜24px |
| アイコン | 16px（資源バー・研究・ボタン） |
| 輪郭 | 濃い紫がかった黒（`#1c1824`）の1px の縁取り |
| 影 | 足元に半透明の黒（`#00000044`）の楕円 |
| 向き | 横向き（右向き）で描く。左向きはゲーム側で反転する |

**アニメのコマ数**

| 種類 | コマ |
|---|---|
| 兵士・魔物 | 歩き4コマ、攻撃4コマ（小さな魔物は攻撃2コマでも可） |
| 建物 | 待機4コマ（煙・旗・火のゆらぎなど。動かない建物は1コマでも可） |
| 門 | 開く8コマ |
| 防衛兵器（砲など） | 8方向（右・右下・下・左下・左・左上・上・右上）＋撃つ6コマ |
| 柵・壁 | つながり方16通り（上・右・下・左のとなりの有無） |
| 効果 | 再生6コマ |

**データの形**（ゲームが読む形。作る人が意識しなくても、こちらで変換できます）：1コマを「1文字＝1色」の文字の行で表す（`.` は透明）。色は1枚につき30色くらいまで。

**今ある絵の雰囲気**：16pxでも誰か分かる、はっきりした形と色。人間側は青・銀・金、魔物側は緑（ゴブリン）・茶（オーガ）・青灰（トロール）・赤（ドラゴン）。

## 3. 材料の色（とても大事）

武器・鎧・壁・資源は、**色だけで材料（段）が分かる**ようにします。形は同じで色だけ変える「色違い」でかまいません。

| 段 | 材料 | 色の目安 | ランク |
|---|---|---|---|
| 0 | 革（鎧だけ） | 茶 `#9a6a3a` | Ⅰ |
| 1 | 鉄 | 灰 `#9aa0a6` | Ⅰ |
| 2 | 鋼 | 青みがかった銀 `#b9d3ec` | Ⅱ |
| 3 | 合金 | 金色がかった銀 `#e2c779` | Ⅲ |
| 4 | 魔金属 | 紫 `#a774ec`（少し光る） | Ⅴ |
| 5 | 聖銀 | 白く光る `#f6faff`（まわりに淡い光） | Ⅵ |
| 6 | 竜晶 | 赤い結晶 `#e05a4e` | Ⅶ |
