# ナイトディフェンス 工業と魔法の絵の依頼書（デザイン引き継ぎ用）

2026-11-20 作成。ランクⅣで「工業」か「魔法」を選ぶと、そこから先の研究・施設・兵・材料が分かれるようにしました。そのために新しく要る絵と、描き直してほしい絵をまとめた依頼書です。この1枚だけで作業できるようにしてあります。絵の決まり（縁取り・影・コマ数）は、これまでの依頼書 `docs/ART_BRIEF.md` と同じです。

## 1. ゲームの説明（短く）

- ブラウザで遊ぶ、ドット絵の街づくり＋防衛ゲーム（ダークファンタジー）。夜になるとアビス（地の裂け目）から魔物の大群が攻めてくる。柵・壁・防衛施設・兵士で守る。
- 城のレベル（Lv1〜7）で「ランクⅠ〜Ⅶ」が開く。**ランクⅣで街の方針を「工業」か「魔法」に決める**（あとから変えられない）。
- **工業**：蒸気・歯車・管・煙の世界（スチームパンク寄り）。石炭で機械を動かし、銃や大砲で戦う。
- **魔法**：エーテル（青白く光る魔法の結晶）の世界。魔術師・ゴーレム・魔法の施設で戦う。
- 画面は暗めの夜が基本。明かりの周りだけが明るい。人間側は青・銀・金。
- **名前・見た目は西洋ファンタジー**。和風のものにはしない。

## 3. 材料の色（変わったところがあります）

**魔金属（紫）はやめて、魔法は「月光石」（エーテルを染み込ませた、水色に光る石。夜に作る）、工業は「黒鉄」（黒い鉄）に分けました。**

| 段 | 材料 | 色の目安 | ランク |
|---|---|---|---|
| 1 | 鉄 | 灰 `#9aa0a6` | Ⅰ |
| 2 | 鋼 | 青みがかった銀 `#b9d3ec` | Ⅱ |
| 3 | 合金 | 黒い鋼に金の縁 `#3a3d4a` | Ⅲ |
| 4（魔法） | **月光石**（金属ではなく石） | **水色 `#7fd8f5`**（月の光のように少し光る）。鎧・兜は水色がかった色 `#8fb4c4` に抑える | Ⅴ |
| 4（工業） | **黒鉄** | **くすんだ灰黒 `#4a4a56`**（光らない・重い感じ。金具は真鍮色 `#c89a4a` でもよい） | Ⅴ |
| 5 | 聖銀（ミスリル） | 白く光る `#f6faff` | Ⅵ |
| 6 | 竜晶 | 赤い結晶 `#e05a4e` | Ⅶ |

- エーテル（魔法の結晶・光）：青白い `#62c6d9`、明るい所 `#c8f4fb`
- 工業の飾り：真鍮色の管・歯車 `#c89a4a`、蒸気の白い煙、石炭の黒

## 4. 描き直してほしい絵（今ある絵の色替え・形替え）

### 4-1. 「魔金属の〜」を月光石（水色）に（優先度 B）

今「魔金属の〜」として紫で描いてある段を、**水色の月光石**に描き直してください。形はそのままで、紫の金属の部分を、水色に光る月光石（石・結晶）に替える程度で十分です。

| もの | 今の絵 | 変えたいところ |
|---|---|---|
| 月光石の壁 | 魔金属の壁 | 壁に月光石の石を組み込み、水色にほのかに光らせる |
| 月光石の門 | 門の魔金属の段 | 同上（開く8コマも） |
| 月光石の大弩 | バリスタの魔金属の段 | 弩の金具を水色に |
| 月光石の迫撃砲 | 迫撃砲の魔金属の段 | 砲身を水色に |
| 月光石の塔 | メイジの塔の魔金属の段 | 塔の金具・飾りを水色に |
| 月光石の前哨砦 | 前哨砦の魔金属の段 | 柵の金具を水色に |
| 月光石の道具 | 伐採所・石切り場・鉱山・炭鉱・金鉱・農場・漁場・エーテル採掘所の「魔金属の道具」の段（8施設） | 置いてある斧・つるはし・農具・銛の刃を水色に |
| 月光石の武器・鎧 | 部隊の武器・鎧の「魔金属」の段 | 刃・鎧を水色に（上の色の目安どおり、鎧は抑えた色） |

### 4-2. 狙撃兵をライフル銃に（優先度 B）

狙撃兵は**工業の兵**になりました。前の依頼の「魔法と火薬のライフル（エーテルの結晶つき）」はやめて、**エーテルの光のない、火薬のライフル銃**にしてください。

| 項目 | 内容 |
|---|---|
| 大きさ・コマ | 16px・歩き4・構えて撃つ4（撃つときに銃口の火と煙） |
| 1部隊 | 3人くらい |
| 役割 | 遠くの大きな魔物を1体ずつ撃ち抜く。3発撃つと長い装填 |
| 見た目 | 長い銃身のライフル銃。黒鉄の銃身に真鍮の金具、筒形の照準器。フードつきの外套、片目に照準用のレンズ。青い光はなし |
