## 決まったこと・考え方（2026-11-11）

- 部隊の武器は種類を分けず、**アップグレードの有る／無し**だけにする。補給が追いつかないときは、一部の部隊が一つ前の武器を使う（分かりやすさ優先）
- 金属などの資源は、**前哨砦を一つ建てないと取りに行けない**くらいの所にある
- 石炭（Ⅱ）：篝火の燃料が木から石炭になって明かり・火力が強くなる。火薬につながる
- 城のシールド：研究で解放し、張るたびに資源を使う
- 聖銀（Ⅵ）：吸血鬼などの敵が出てきて、銀が効く
- 竜晶（Ⅶ）：最後のアイテム。取る方法はもう少し増やしたい（ボス・ドラゴン・駐留地の竜の巣など）
- 魔術師はランクⅣ、竜騎兵はランクⅤ（魔術師のあと）、魔導砲はランクⅤ
