## 魔物のアイデア（採用したもの・2026-11-11）

- **モウラー**（モグラ型の魔物）：地面を掘って柵の下から入り込む
- **盾持ちオーガ**：前からの矢を防ぐ。横や後ろからなら当たる
- **サラマンダー**（燃えている魔物）：体が燃えていて、触れた木の施設に火がつく。石の壁には効かない
- **巨大コウモリ**：夜に空から群れで来る。明かりを嫌う
- **吸血鬼**：倒した兵を魔物に変える。銀が効く（ランクⅥのころ）
- **グール**：倒れた魔物の死体を食べて回復・大きくなる
- **ストーンゴーレム**：とても硬く、城壁を一撃で壊す。魔法がよく効く
- **ボスはステージごとに変える**（今はゴブリンキングだけ）
- 武器工房は段階を上げないと上の装備を作れない（エーテルの装備は下の工房では作れない）

- 資源：Ⅰ 木と石（鉄は武器だけ）→ Ⅱ 石炭・鉄の強化 → Ⅲ 火薬・合金・金鉱 → Ⅳ エーテル → Ⅴ 魔金属 → Ⅵ 聖銀 → Ⅶ 竜晶
- 石炭（Ⅱ）：篝火が木から石炭になって明かり・火力が強くなる。火薬につながる
- 部隊の武器は種類を分けず、**アップグレードの有る／無し**だけにする。補給が追いつかないときは一部の部隊が一つ前の武器を使う（※今の本編には装備の種類（槍・長弓・戦斧・クロスボウ・雷の杖など）がある → 整理が要る）
- 金属などの資源は、**前哨砦を一つ建てないと取りに行けない**くらいの所にある
- 城のシールド：研究で解放し、張るたびに資源を使う
- 聖銀（Ⅵ）：吸血鬼などが敵に出てきて、銀が効く

## アイデアのメモ（2026-11-13 ユーザー・まだ決めない）

- **城Lv4〜5くらいから「魔法」と「科学」に分かれる**（どちらかに特化する分岐）。科学の方は空の戦力に**気球船**（石炭と飛膜で飛ぶ）など
- **素材を2種類に分ける**：自分たちで取れるもの（木・石・鉄・石炭…）と、**魔物からしか取れないもの**。施設を建てる・建てないの取捨選択が起きるように
  - 魔核（一般的な魔物から）
  - **飛膜**（空を飛ぶ魔物＝ハーピー・ドラゴンからだけ）
  - **龍鱗**（ドラゴン・シーカーからだけ）
- 素材が増えすぎると複雑になる。**短い時間に要素を詰め込みすぎない、でもプレイヤーが飽きない**くらいを目指す
- **流れ**：城Lvが上がる → 研究と新しい施設の建築が始まる → それが軌道に乗ってきたころに**新しいタイプの敵**が出てくる
- 新しいタイプの敵が出てくるとき、**索敵の力に応じて、先にその敵の特徴が分かる**と面白い
- **施設のLvをなくす**かも：強化は研究と**改築**（バリスタを木から鉄に、など。改築が実質のLv上げ）にする
