## 1. ゲームの説明（短く）

- ブラウザで遊ぶ、ドット絵の街づくり＋防衛ゲーム（ダークファンタジー）。
- 昼に街を育て、夜になるとアビス（地の裂け目）から魔物の大群が攻めてくる。柵・壁・防衛施設・兵士で守る。夜にこちらから魔物の陣地へ攻め込むモード（駐留地攻撃）もある。
- 城のレベル（Lv1〜7）で「ランクⅠ〜Ⅶ」が開き、材料が **鉄 → 鋼 → 合金 → 魔金属 → 聖銀 → 竜晶** と良くなっていく。
- 画面は暗めの夜が基本。明かりの周りだけが明るい。人間側は青・銀・金、魔物側は緑・茶・青灰・赤。

## 2. 頼みたいもの（それぞれ）

- **ドット**：マップや戦場に出る小さな絵（歩き4コマ・攻撃4コマ。右向きで描く）
- **立ち絵**：選んだときの大きな絵（情報パネルの上・図鑑）

## 4. 新しく頼む部隊

### 4-1. エーテルゴーレム（ランクⅤ）

| 項目 | 内容 |
|---|---|
| 大きさ・コマ | 16px（ゲームで拡大して、兵士の2倍くらいの大きさで出す）・歩き4・殴る4 |
| 1部隊 | **1体**（大きな1体で1部隊） |
| 目的・役割 | **とても硬い壁役**。前に立って魔物を受け止め、門や味方の前をふさぐ。足は遅い。攻撃は重い拳でたたく |
| どう作る | 兵器工房で、**エーテル（青く光る魔法の結晶）を使って**組み上げる。生き物ではなく、作られた兵器 |
| 見た目 | 石や金属の塊を組み合わせた人型。胸や関節の割れ目から**青白いエーテルの光**がもれている（エーテルの色 `#62c6d9`・明るい所 `#c8f4fb`）。顔は目の光だけ。重たく、ずんぐり |
| 気をつけること | 魔物のストーンゴーレム（とても硬い敵）も別に作る予定。**こちらのゴーレムは人間側らしく、青・銀・金の飾りや紋章**を入れて見分けがつくように |

### 4-2. 狙撃兵（ランクⅤ）

| 項目 | 内容 |
|---|---|
| 大きさ・コマ | 16px・歩き4・構えて撃つ4（撃つときに銃口の光） |
| 1部隊 | 3人くらい |
| 目的・役割 | **遠くの大きな魔物を1体ずつ撃ち抜く**。射程がとても長く、一発が重い。撃つのが遅く、魔物の群れに近づかれると弱い |
| 武器 | **魔法と火薬のライフル**。長い銃身に、エーテルの結晶（青く光る）や魔法の刻印がはめこまれている。撃つと火薬の煙と、青い魔法の光の筋 |
| 見た目 | 軽い装備。フードつきの外套かマント、片目に照準用のレンズや眼帯。長い銃を肩にかついで歩く。兵士より細身 |
| 色 | 人間側の青・灰の服に、銃のエーテルの青い光がワンポイント |

### 4-3. 銀装兵（ランクⅥ）

| 項目 | 内容 |
|---|---|
| 大きさ・コマ | 18px（兵士・重装歩兵と同じ）・歩き4・攻撃4 |
| 1部隊 | 兵士と同じくらいの人数 |
| 目的・役割 | **歩兵の上位**。聖銀は「軽くて硬い」金属なので、**重装歩兵のように硬いのに、足は速い**。どんな魔物にも使える主力の歩兵。吸血鬼などに少し強いのはおまけ（**吸血鬼専用の部隊ではない**） |
| 見た目 | 全身を覆う、**白く光る聖銀の鎧**（聖銀の色 `#f6faff`、まわりに淡い光）。重装歩兵のようなごつさではなく、**すっきり細身で動きやすい形**。剣と、中くらいの盾 |
| 気をつけること | 重装歩兵（大盾・戦斧・ずんぐり）と並べたときに、**「軽くて速そう」**に見えること |

### 4-4. グリフォン騎兵（ランクⅥ）

| 項目 | 内容 |
|---|---|
| 大きさ・コマ | 16〜24px（騎兵と同じくらい）・**飛ぶ4**・**降りて攻撃4**・（あれば）着地2・飛び立つ2 |
| 1部隊 | 騎兵と同じくらい（数騎） |
| 目的・役割 | **移動は空を飛んで速い**（柵・山・川を越えて、離れた所へすぐ駆けつける）。**攻撃するときは地上に降りて**、槍で戦う。降りている間は地上の魔物から攻撃される。打たれ弱め |
| 見た目 | グリフォン（鷲の頭と翼・ライオンの体）に、軽い鎧の騎士が乗る。槍を持つ。グリフォンは茶と白、騎士は人間側の青・銀 |
| 気をつけること | 竜騎兵（赤い竜・空から攻撃する部隊）と並べたときに、**「速くて身軽」**に見えること。飛んでいるときと、降りて戦っているときの違いがひと目で分かること |

## 5. 装備の段で見た目が変わる部隊

部隊は武器と鎧の段（材料）が上がると、ゲームの中で色が変わります（今はプログラムで色だけ塗り替えている仮）。新しい部隊も、段が上がるほど少し豪華になるとうれしいです（材料の色は `docs/ART_BRIEF.md` の「材料の色」と同じ）。

| 部隊 | 変わる所 |
|---|---|
| エーテルゴーレム | （段はなし。エーテルの光で十分） |
| 狙撃兵 | 銃身の金属の色（魔金属 → 聖銀 → 竜晶） |
| 銀装兵 | 最初から聖銀の鎧。剣の色だけ段で変わる（聖銀 → 竜晶） |
| グリフォン騎兵 | 槍の穂先と鎧の色（聖銀 → 竜晶） |
