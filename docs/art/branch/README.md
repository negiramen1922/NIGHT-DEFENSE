# 工業と魔法の絵（ART_BRIEF_BRANCH）

- `sprites_branch_A.json`：絵のデータ（pal＝1文字→色、anims＝コマ→行の配列、`.`＝透明）
  - `icons`：歯車・黒鉄・エーテル金属・合金、エーテルの武器・鎧
  - `units`：狙撃兵（魔法のライフル）・蒸気機兵・空の魔術師・蒸気戦車・巨大ゴーレム・銃士の気球・爆撃飛行船・空飛ぶクジラ
  - `buildings`：機械工房・高炉・銃士の塔・魔核の動力炉・ガス灯・錬金工房・照明弾の発射台
  - `weapons`：重砲・大要塞砲（上から見た図 dirs×8＋fire×6）
  - `traps`：地雷・トラバサミ（set×1＋trigger×6）
  - `projectiles`：照明弾
  - `sprites` / `tool_tiers`：エーテル金属の段
- `sprites_branch_blackiron.json`：黒鉄の段（エーテル金属の段と同じ形で、色だけ違う）
- `png/`：確認用の画像
  - `キー_動き.png`：コマを横に並べたもの
  - `キー_art.png`：立ち絵（100×40・4コマ）

兵器の dirs の順は 右→右下→下→左下→左→左上→上→右上。立ち絵は横から見た図です。

## 試作版への入れ方（2026-11-20）
- `proto/index.html` の `NDSPR_BRANCH` に変換して入れた（`tools` で作ったのではなく、このフォルダの json から）
- 「エーテル金属」の段は、ゲームでは「月光石」（魔法）の段として使う。黒鉄の段は工業の街のときに切り替える（`polText`）
- 素材のアイコン `res_ether`（インゴット）は使っていない。月光石は三日月の石のアイコン
- `gunbase_*`（櫓台）はやめた施設なので使っていない
- 照明弾の発射台・大要塞砲・照明弾はまだゲームにない（入れるときに使う）
