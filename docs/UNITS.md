# ナイトディフェンス 兵士の一覧と「強い」の案

2026-11-17 作成（試作版 ver 1.12 の時点の数字）。兵士と魔物の相性（じゃんけん）を決めるための資料です。**相性は「強い」だけ**を作る（「弱い」は作らない：ユーザーの指定）。

- 1秒の火力：部隊全体の合計（人数 × 1発 ÷ 撃つ間隔）。研究・英雄・熟練度・装備の上乗せは入れていない
- 射程：ゲームの表示と同じマス
- 「試」：試作版だけの兵（本番にはまだない）。「雇」：金貨で雇う冒険者

## 3. 「強い」の案（未決）

強い相手には火力が上がる（倍率は未定。例：1.5倍）。ボスには相性は効かない案。

| 兵士 | 強い相手 | 理由 |
|---|---|---|
| 農兵 | — |  |
| 剣士 | 小型 | 数で群れを受け止める |
| 弓兵 | 小型 | 弱い魔物を数多く倒す |
| 斥候 | —（偵察用） |  |
| 重装歩兵 | 大型 | 大きな魔物の一撃を受け止める |
| 騎兵 | 大型 | 勢いのある一撃で大きな魔物を崩す（ユーザーの例） |
| 銃兵 | 大型 | 1発が重いので、体力の多い魔物を削る |
| チャリオット | 大型 | 大きな魔物でも止まらず轢いていく |
| 砲兵 | 小型 | 範囲攻撃で群れを崩す |
| 魔術師 | 小型 | 範囲魔法で群れを崩す |
| ドラゴンライダー | 竜型 | 竜には竜で |
| 狙撃兵 | 竜型 | 遠くから硬いものを撃ち抜く |
| エーテルゴーレム | 大型 | 体力で大型と殴り合う |
| 銀装兵 | 竜型 | 聖銀は竜のうろこを通す（設定の案） |
| グリフォン騎兵 | 竜型 | 空で竜と戦える |
| 剣士の一団 | — |  |
| 狩人の一団 | — |  |
| 魔導士の一団 | 小型 | 範囲攻撃 |

分類ごとにまとめると：

- **小型に強い**：剣士・弓兵・砲兵・魔術師・魔導士の一団
- **大型に強い**：重装歩兵・騎兵・チャリオット・銃兵・エーテルゴーレム
- **竜型に強い**：狙撃兵・ドラゴンライダー・銀装兵・グリフォン騎兵

## 4. 決まっていないこと

- 「中型」を作るかどうか（今の分け方では作らない案）
- ボスを「超大型」にするか、ボス枠（相性なし）にするか
- 倍率（例：1.5倍）
- 防衛施設にも「強い」をつけるか
