# ナイトディフェンス 新しい魔物の絵の依頼書（デザイン引き継ぎ用）

2026-11-13 作成。敵の整理（`docs/ENEMIES.md`）で新しく決まった魔物のうち、**まだ絵がないもの**をまとめた依頼書です。この1枚だけで作業できるようにしてあります。絵の決まり（縁取り・影・コマ数）は、これまでの依頼書 `docs/ART_BRIEF.md` と同じです。

## 1. ゲームの説明（短く）

- ブラウザで遊ぶ、ドット絵の街づくり＋防衛ゲーム（ダークファンタジー）。夜になるとアビス（地の裂け目）から魔物の大群が攻めてくる。柵・壁・防衛施設・兵士で守る。
- 画面は暗めの夜が基本。明かりの周りだけが明るい。魔物側は緑（ゴブリン）・茶（オーガ）・青灰（トロール）・赤（ドラゴン）など。
- ステージは **草原・沼地・山脈・雪原・荒野**。ステージごとに、出てくる魔物を少し変える。
- **同じ中身で見た目が違う魔物**も作って、ステージごとに楽しめるようにしたい。
- 名前・見た目は西洋ファンタジー（和風にしない）。

## 3. 頼みたい魔物

### 3-1. トレント（草原・ランクⅣ）

| 項目 | 内容 |
|---|---|
| キー | `e_treant` |
| 大きさ・コマ | 20px・歩き4・攻撃4（枝の腕でたたく） |
| 優先度 | A |
| 役割 | **硬い**魔物。**火に弱い**（ドラゴンブレス・竜騎兵・魔術師の火がよく効く）。特徴はそれだけのシンプルな魔物 |
| 見た目 | 歩く巨木。幹に顔（暗い洞の目と口）、枝の腕、根の足。濃い茶の樹皮に暗い緑の葉。夜なので目の奥がうっすら光る |

### 3-2. エルダートレント（草原・20回目の中ボス）

| 項目 | 内容 |
|---|---|
| キー | `e_elder_treant` |
| 大きさ・コマ | 24〜28px（ゲームで大きく拡大）・歩き4・攻撃4 |
| 優先度 | A |
| 役割 | 草原の**中ボス**。トレントの長。とても大きくて硬い。火に弱い |
| 見た目 | トレントよりずっと大きく、年老いた巨木。苔やつる、白くなった古い樹皮、頭に枯れかけた大きな枝の冠。**普通のトレントと並べて「親玉」と分かる**こと |

### 3-3. ワーウルフ（ブラッドムーン・21回目から）

| 項目 | 内容 |
|---|---|

### 3-4. マンイーター（食人植物・見た目違いをいくつか）

| 項目 | 内容 |
|---|---|
| キー | `e_maneater`（基本）＋ 見た目違い（下の表） |
| 大きさ・コマ | 16px・歩き4（根で這って歩く）・攻撃4（大きな口で噛みつく） |
| 優先度 | A（基本）／B（見た目違い） |
| 役割 | 根で歩いて近づき、**噛みついて毒にする**（兵士に少しずつダメージ）。中身はどれも同じで、**見た目だけステージで変える** |
| 見た目（基本） | 大きな口を持つ花のつぼみ。口の中に牙、口のまわりに花びら。茎と葉、根の足。口からよだれ（毒） |

**見た目違い**（形は同じで、色・花の形を変える。中身は同じ）

| キー | ステージ | 見た目 |
|---|---|---|
| `e_maneater` | 草原 | 緑の茎に赤い花びら（基本） |
| `e_maneater_swamp` | 沼地 | 濁った緑と紫。花びらがしおれて、毒の泡 |
| `e_maneater_snow` | 雪原 | 白っぽい茎に青い花びら。霜がついている |
| `e_maneater_desert` | 荒野 | サボテンのようなとげのある茎に、黄色い花 |
