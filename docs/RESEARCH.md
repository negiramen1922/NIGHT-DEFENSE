**決まったこと（2026-11-17 追加・こちらのチャット。下の古い書き方より優先）**
- **言葉**：「改築」は「**アップグレード**」に統一（「改造」と見まちがえやすいため）。**城は「ランクが上がる」**、**ほかの施設は「アップグレードでランクが上がる」**（施設の段も「ランク」と呼ぶ）。「**レベル**」は**英雄のレベルだけ**に使う。ゲームの画面・せりふ・資料の言い換えは研究の整理と一緒にやる
- **防衛**：アップグレードは城のランクが上がると自動で開く。実際にアップグレードするにはターンと資材がかかる。研究は**改造**（動きや特性が変わる）だけ。改造もアップグレードと同じくターンと資材がかかる
- **門と壁**：アップグレードにターンはかけない（すぐ終わる。資材はかかる）
- **部隊**：研究は新しい兵科のときだけ。剣術などの%の研究はなくす。装備は**部隊ごとに防具と武器（剣・銃など）を設定する**方向（まとめて持ち替えると資材が重すぎるため。2026-11-17 ユーザー「いいかも」）
- 整理ボードは https://claude.ai/artifact/K4cx9jLcpKJ7hrQAf1HawE を使う（ユーザー：こちらのほうが使いやすい）

- **生産**（2026-11-17 決定）：1つずつアップグレードして資材を払う。**ターンなし**（すぐ終わる）。アップグレードは城のランクが上がると自動で開く（防衛と同じ）。研究は「新しい施設」と「改造」だけ。操作は部隊の装備と同じく、**施設の詳しい画面で、使う道具を選んで替える**（例：石の農具 → 鉄の農具）。一括アップグレードもあり（「農場 ×8（鉄 −40）」の一覧 → はい／いいえ。足りなければ払える数だけ）。**道具は毎ターン少しずつ減る**：はじめは木材や石、鉄の道具なら鉄、のように使っている道具の材料を毎ターン使う。下の「生産：1つずつの改築はなくす・研究で全部まとめて」は取り消し
- **部隊**（2026-11-17 決定）：兵科は決まっていて、武器と防具の**材料だけが上がる**（鉄の剣 → 鋼の剣、鉄の鎧 → 鋼の鎧）。部隊ごとに詳しい画面で替える。資材を払ってすぐ替わる。一括もあり。**熟練度はなくす**。今の装備が最新かどうかは、部隊の札とマップに武器・防具のアイコン（剣士の分は全素材の絵がある：`eqIcon`・`wpn_iron〜dragon`・`arm_leather〜holy`）と、替えられるときの「↑」で分かるようにする（案）
- **英雄だけレベルがある**。**英雄1人を1部隊として扱う**（2026-11-18 決定）。下の「英雄は部隊の隊長（案2）」は取り消し
- **城のランクが上がったときのお知らせ**に、開いたものを**アイコン付きで**並べる（特に新しい建物はアイコンをしっかり。2026-11-18）：「生産：鉄の農具・鉄のピッケルが使えるようになりました」「部隊：鉄の剣・鉄の鎧が使えるようになりました」「防衛：〇〇がアップグレードできるようになりました」など
- **小数をなくす**（2026-11-18 決定）：生産量も消費量も、1ターンあたりの数を整数にする（今は小数の消費があって分かりにくい）。数字全体を大きくして小数が出ないようにする。研究の整理と一緒にやる
- **英雄の見た目を作れるようにする**（2026-11-18 ユーザー）：パーツの付け替え（髪型・目の形・髪の色・目の色など）と名前を付けられる。**研究と生産の整理が終わってから**やる

- **工業の研究を足す**（2026-11-18 決定）。街の研究方針（工業／魔法）は、研究と生産の整理が終わってから

**決まったこと**
- 施設の種類で育て方を分ける（案A・5章）：
  - 生産：1つずつの改築はなくす。研究＝道具の進化（Ⅰ+30%・Ⅱ鉄+80%・Ⅲ鋼+100%・Ⅳ〜Ⅶ+60%＝5.5倍。5-8）。その種類の施設が全部まとめて鉄・鋼の見た目に（「改築ごとに見た目を変えたい」絵の依頼は、この研究の段ごとの見た目として頼む）。城のランクで2×2の大きな施設
  - 防衛：新しい施設は研究。改築は城のランクで自動に解放（1つずつ改築）。研究は改造（動きが変わる）だけで、%の研究はなくす
  - 部隊：新しい兵科は研究・建物。%（剣術など）はなくす。**兵士1部隊ずつの育成（熟練度を増やす・訓練）はしない**（管理することが多すぎる：2026-11-17 ユーザー）。熟練度は今の3段のまま、戦えば自然に上がるおまけ。兵士は装備の段で全部隊まとめて強くなる（城のランクで。案は 5-9）
  - **英雄は部隊の隊長**（2026-11-17 決定・案2）：戦闘の英雄は部隊に入って、その部隊の強さ・見た目（旗）を変える。英雄が育つとその部隊も強くなる。育てる楽しみと愛着は英雄に集める。内政の英雄は今のまま生産施設に付ける
  - 内政：研究のまま。新しい建物も研究
- 斥候のLv（5-7）：0 方向／1 駐屯地のおおよその場所／2 全体の数と魔物の分類／3 駐屯地の場所（駐屯地攻撃はここから）と具体的な種類／4 方向ごとの数。上限は城のランク。斥候の部隊で早く見つける仕組みはなくす
- 相性（`docs/UNITS.md`）：「強い」だけ（強い相手に火力2倍）。騎兵・チャリオット＝大型、ハープーンランチャー＝竜型だけ。魔物は 小型・大型・竜型・ボス枠
- 前提の不自然なもの・古い説明は直した（4-6・試作版）
- 魔核タブはほかのタブに混ぜる（4-3）

## 3. 気になる点

1. **改築の研究が多い**（127のうち26。全体の約2割）。「生産の改築Ⅱ」「鉱山の改築Ⅱ」「工房の改築Ⅱ」…と、タブごと・ランクごとに並んでいて、研究画面が埋まる。中身は「改築できるようになる」だけで、選ぶ楽しさがない
2. **防衛タブだけ大きい**（44）。内政（11）・魔核（12）は少なく、魔核タブはランクⅢまでしかない。内政はランクⅤがない
3. **ランクⅤ〜Ⅶが薄い**：多くが「○○を建設できる」1つだけで、その後の強化がない（例：テスラタワー・ミスリルレイ・ドラゴンブレスに、火力の研究がない）
4. **工業と魔法の偏り**：ランクⅢは工業（火薬・大砲・迫撃砲・銃兵）、ランクⅣ以上はほとんど魔法。工業のランクⅣ以上は5つ（砲兵・砲術・特殊砲弾・ハープーン・狙撃兵）、魔法は16
5. **同じような効果が2つのタブにある**：生産タブ「伐採技術（+30%）」と魔核タブ「強化斧（+25%）」など。どちらも産出を上げるだけ
6. **置き場所が分かりにくい**：魔術師・竜騎兵は部隊タブ、メイジの塔・バリアは防衛タブ。斥候（偵察の研究）は部隊タブのランクⅠ、斥候隊はランクⅡ
7. **前提が不自然なもの**：投石機の前提が「鋼弦（バリスタの火力）」。火薬の前提が「大岩弾（投石機の火力）」
8. **説明が古いもの**：師団「今はランクⅢ。ランクを伸ばしたらⅥのつもり」（今はランクⅤ）。延長シフト・徹夜シフトの「深夜残業」（今の画面の名前は「夜なべ」）。砲兵「射程12」

### 5-5. 部隊の育成（%の研究をなくすかわり）

### 5-5b. 2026-11-17 ユーザーの返事（第3版への追記）
- **訓練は1ターンごと**（時間に比例すると放置ゲームになるので）：「訓練」にした部隊は、「夜へ」のたびに決まった熟練度が入る（金貨・食料を使う）。実戦のほうがずっと多く入る
- **生産を施設の数だけにする（研究の%もなくす）案**：途中で詰む見込みが高い。今は終盤の伐採所1つが、改築（Lv3で2.0倍）×研究（城ランク5で伐採技術 +150% ＝2.5倍）でおよそ5倍作っている。これをなくすと同じ量に5倍の数が要るが、施設の上限は城Lv7でも170（前哨砦なし）で、森・鉱脈のマスと埋蔵量も足りなくなる
- **ユーザーの希望**：鉄の斧などで生産性を上げ、技術の進化とつなげたい → 生産は次の形（案）:
  - **研究＝道具の進化**：伐採技術 Lv1 石の斧 → Lv2 鉄の斧 → Lv3 鋼の斧 …（%が上がり、その種類の施設が全部まとめてその見た目に）。1つずつの改築はなくす
  - **城のランク＝大きな施設**：大農場・大伐採所などの2×2（施設の数は1つ。小さい施設4つ分より少し多く作る）と、新しい素材の施設（炭鉱・金鉱など）。施設の上限と手間の問題をまとめて解く
- **研究画面を「つながった木」に**：ブロックとブロックを線で結び（前提 → 次）、ブロックにLvの●○を出す。どれが何の前提か、どこまで育てたかが一目で分かる

### 5-6. 決めてほしいこと
1. **新しい生産施設（炭鉱・金鉱など）は城のランクで解放**でよいか（おすすめ：はい。城を上げる意味がはっきりする）
2. **生産施設の改築**：1つずつの改築をなくし、研究のLvで全部まとめて上の段の見た目にする、でよいか
3. **内政の建物の改築**（5-4）：住居は生産と同じ、兵舎などは防衛と同じ、でよいか
4. **部隊の装備（鎧・武具）**：
   - 研究のまま（おすすめ：補給で使う素材が変わる＝いつ切り替えるかを選ぶ楽しさがある）
   - 城のランクで自動（防衛の改築と同じ考え。ただ、合金を作っていないのに合金の補給が要るようになる）
5. **訓練**のやり方（5-5）：兵舎の近くで時間で上がる、でよいか。訓練場という建物を足すか
