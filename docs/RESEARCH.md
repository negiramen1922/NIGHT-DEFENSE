## 3. 気になる点

1. **改築の研究が多い**（127のうち26。全体の約2割）。「生産の改築Ⅱ」「鉱山の改築Ⅱ」「工房の改築Ⅱ」…と、タブごと・ランクごとに並んでいて、研究画面が埋まる。中身は「改築できるようになる」だけで、選ぶ楽しさがない
2. **防衛タブだけ大きい**（44）。内政（11）・魔核（12）は少なく、魔核タブはランクⅢまでしかない。内政はランクⅤがない
3. **ランクⅤ〜Ⅶが薄い**：多くが「○○を建設できる」1つだけで、その後の強化がない（例：テスラタワー・ミスリルレイ・ドラゴンブレスに、火力の研究がない）
4. **工業と魔法の偏り**：ランクⅢは工業（火薬・大砲・迫撃砲・銃兵）、ランクⅣ以上はほとんど魔法。工業のランクⅣ以上は5つ（砲兵・砲術・特殊砲弾・ハープーン・狙撃兵）、魔法は16
5. **同じような効果が2つのタブにある**：生産タブ「伐採技術（+30%）」と魔核タブ「強化斧（+25%）」など。どちらも産出を上げるだけ
6. **置き場所が分かりにくい**：魔術師・竜騎兵は部隊タブ、メイジの塔・バリアは防衛タブ。斥候（偵察の研究）は部隊タブのランクⅠ、斥候隊はランクⅡ
7. **前提が不自然なもの**：投石機の前提が「鋼弦（バリスタの火力）」。火薬の前提が「大岩弾（投石機の火力）」
8. **説明が古いもの**：師団「今はランクⅢ。ランクを伸ばしたらⅥのつもり」（今はランクⅤ）。延長シフト・徹夜シフトの「深夜残業」（今の画面の名前は「夜なべ」）。砲兵「射程12」

## 4. 整理の案（たたき台）

### 案1：改築を研究から外す（おすすめ）
- 城のランクが上がったら、そのランクの改築は全部できるようになる（城の強化とセットにする）
- 研究画面から26個が消えて、「新しいもの」と「強くするもの」だけになる
- 城のランクアップの案内（リリア）で「○○を改築できるようになりました」と伝える

### 案2：タブごとの役目をはっきりさせる
| タブ | 役目 |
|---|---|
| 生産 | 資源を増やす・新しい素材 |
| 内政 | 住民・幸福度・夜の過ごし方・交易 |
| 防衛 | 防衛施設・壁・罠 |
| 部隊 | 兵・装備・部隊のまとまり |
| 魔核 | 魔物から得た力（魔核を使う特別な研究） |

魔術師・竜騎兵（兵）は部隊、メイジの塔・バリア（施設）は防衛、のままでよいか。魔核タブを「魔核を使う研究」としてランクⅦまで伸ばすか、ほかのタブに混ぜてなくすか。

### 案3：各ランクに「新しいもの＋強くするもの」をそろえる
ランクⅤ〜Ⅶの新しい施設・兵には、それぞれ1つずつ強化の研究をつける（例：テスラタワーの連鎖+1、ドラゴンブレスの範囲+30%）。

### 案4：工業の研究を足す（方針を入れる前に）
ランクⅣ〜Ⅶに工業の研究を、魔法と同じくらいの数まで足す。ネタの案：重砲（大砲の上位）、連弩（バリスタの連射）、鉄の要塞（壁）、蒸気機関（生産）、機械仕掛けの罠、火薬の改良 など。

### 案5：重なり・古い説明を直す
「強化斧」などの魔核の産出アップは、生産タブの「伐採技術」などとまとめる。前提の不自然なもの（投石機・火薬）、古い説明（師団・延長シフト・砲兵）を直す。
