## 3. 気になる点

1. **改築の研究が多い**（127のうち26。全体の約2割）。「生産の改築Ⅱ」「鉱山の改築Ⅱ」「工房の改築Ⅱ」…と、タブごと・ランクごとに並んでいて、研究画面が埋まる。中身は「改築できるようになる」だけで、選ぶ楽しさがない
2. **防衛タブだけ大きい**（44）。内政（11）・魔核（12）は少なく、魔核タブはランクⅢまでしかない。内政はランクⅤがない
3. **ランクⅤ〜Ⅶが薄い**：多くが「○○を建設できる」1つだけで、その後の強化がない（例：テスラタワー・ミスリルレイ・ドラゴンブレスに、火力の研究がない）
4. **工業と魔法の偏り**：ランクⅢは工業（火薬・大砲・迫撃砲・銃兵）、ランクⅣ以上はほとんど魔法。工業のランクⅣ以上は5つ（砲兵・砲術・特殊砲弾・ハープーン・狙撃兵）、魔法は16
5. **同じような効果が2つのタブにある**：生産タブ「伐採技術（+30%）」と魔核タブ「強化斧（+25%）」など。どちらも産出を上げるだけ
6. **置き場所が分かりにくい**：魔術師・竜騎兵は部隊タブ、メイジの塔・バリアは防衛タブ。斥候（偵察の研究）は部隊タブのランクⅠ、斥候隊はランクⅡ
7. **前提が不自然なもの**：投石機の前提が「鋼弦（バリスタの火力）」。火薬の前提が「大岩弾（投石機の火力）」
8. **説明が古いもの**：師団「今はランクⅢ。ランクを伸ばしたらⅥのつもり」（今はランクⅤ）。延長シフト・徹夜シフトの「深夜残業」（今の画面の名前は「夜なべ」）。砲兵「射程12」

- **熟練度を7段に**（新兵 → 一人前 → 熟練 → 精鋭 → 歴戦 → 英傑 → 伝説 など）。段ごとに火力・耐久が少しずつ上がる。剣術・弓術をなくしたぶんは、ここで取り戻す
- **育成の上限は城のランク**（城Lv3 なら3段目まで、など）。研究「精鋭」のかわり
- **訓練**：昼のあいだ、部隊を兵舎（や訓練場）の近くで「訓練」にすると、時間で少しずつ熟練度が上がる（金貨・食料を使う）。実戦のほうがずっと早く上がる。訓練中は動かせない／夜は解除
- 英雄の配属・装備（5-6）と合わせて、「育てた部隊を失いたくない」気持ちを強くする

### 5-6. 決めてほしいこと
1. **新しい生産施設（炭鉱・金鉱など）は城のランクで解放**でよいか（おすすめ：はい。城を上げる意味がはっきりする）
2. **生産施設の改築**：1つずつの改築をなくし、研究のLvで全部まとめて上の段の見た目にする、でよいか
3. **内政の建物の改築**（5-4）：住居は生産と同じ、兵舎などは防衛と同じ、でよいか
4. **部隊の装備（鎧・武具）**：
   - 研究のまま（おすすめ：補給で使う素材が変わる＝いつ切り替えるかを選ぶ楽しさがある）
   - 城のランクで自動（防衛の改築と同じ考え。ただ、合金を作っていないのに合金の補給が要るようになる）
5. **訓練**のやり方（5-5）：兵舎の近くで時間で上がる、でよいか。訓練場という建物を足すか
