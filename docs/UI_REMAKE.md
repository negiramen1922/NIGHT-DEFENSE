## 1. 今の画面と、困っていること

**今の画面（PC）**
- 左：マップ（`#left` > `#mapWrap` > `#cv`）
- 右：選んだものの詳しい欄（`#right` > `#info` / `#infoBody`）と、タブ（`#rtabs`：建設 `#build`・研究・軍事 `#armyBox`・街 `#econ`）
- 上：日付・襲撃までの日数（`#wave`）、1日の長さのバー（`#rtBar`）、資源の欄（`#resbar`）
- 下：ボタン（`#controls`：夜へ `#bNext`・速さ `#bSpd`・一時停止 `#bPause`・一括 `#bBulk`・依頼 `#bOrd`・記録 `#bHist` など）と通信ログ（`#log`）
- スマホは右の欄が下からの引き出し（`#sheetHandle`）になる。置く場所の決定は `#bpad`（`#bpOk` 建てる／`#bpCancel` やめる）

**困っていること（ユーザーの言葉から）**
1. 右と下のメニューが場所をとって、**マップが小さい**。
2. 詳しい欄をよく見ないと、**何ができるかが分からない**。仕組みを知っている人でないと、**エンチャント・強化（アップグレード）・装備には絶対に気づかない**。
3. スマホ・タブレットでの操作もよくしたい。

## 2. 目指す形（決まったこと）

### 2-1. マップを画面いっぱいに
- 右の欄（`#right`）は常には出さない。マップ（`#cv`）を画面いっぱいにする。
- 上の資源の欄と日付・1日のバーは、**細い1段**にまとめてマップの上に置く。
- 下のボタンは、**マップの上に重ねた小さなボタン**にする。**「夜へ」だけは大きく、右下**。
- 通信ログは、必要なときに開く形（小さくたたむ）。

### 2-2. 建設ボタン → 一覧 → 置く場所を決める
- マップの**右下（夜へのとなり）に「建設」ボタン**を重ねて置く。
- 押すと、**建物の一覧**が出る（防衛・領地・部隊のタブ。アイコン・名前・費用。今の `renderBuild()` の中身と同じ情報）。
- 選ぶと**置く場所を決める状態**になる（今の `enterBuild(type)` と同じ）。
  - PC：今までどおりクリックで置く。数字キー（Shift＋数字キー）で選ぶのもそのまま使えるように。
  - スマホ：指で置く場所を動かして、「ここに建てる」「やめる」で決める（今の `#bpad` を使う）。

### 2-3. 押した物の上に「半円のボタン」
施設や部隊を押すと、**その上に半円の形でボタンが並ぶ**。ここから操作する。

- ボタンは**アイコン＋名前**。指で押しやすい大きさ（目安 44px 以上）。
- **まだ使えないものも灰色で出して、押すと理由を出す**（例：「研究『防衛のエンチャント付与』で使えます」「襲撃の日に使えます」）。これで、エンチャントや装備があること自体に気づけるようにする。
- **押した物がマップの上の端などにあって、半円が画面からはみ出すときは、画面（カメラ）が動いて、押した物の上に半円が出せる位置まで寄せる**（ユーザーの指定。半円を下向きにするのではなく、画面のほうを動かす）。
- 何もない所を押すか、もう一度押すと閉じる。

**出すボタン（案。並びや中身はユーザーと決めながら）**

| 押したもの | ボタン |
|---|---|
| 施設（防衛） | 見る・強化（アップグレード）・改造・エンチャント・**魔核の守り石**（魔法の研究「魔核の守り石」のあと）・修理・解体 |
| 施設（生産） | 見る・強化（道具を替える／アップグレード）・作るもの（精錬所・火薬工房など、選べるものだけ）・エンチャント・修理・解体 |
| 施設（兵の施設：兵舎・馬小屋（大きな厩舎）・錬金工房・蒸気の工場・兵器工房） | 見る・兵を作る・強化・修理・解体 |
| 城 | 見る・城の強化・研究・依頼 |
| 部隊 | 見る・迎撃・固守・帰還・補給・装備・エンチャント |
| 何部隊かをまとめて選んだとき | まとめて迎撃・固守・帰還・補給 |

- 今の詳しい欄（`renderInfo()`）の中にあるボタンを、半円から呼ぶ：
  - 修理 `#iRep`、解体 `#iDemo`、アップグレード `#iUpg`（城の強化は `#iBaseUp`）、補給 `#iSup`
  - 改造：`modBlock(o)` の中のボタン（`data-mod`）→ `setMod(type,id)`
  - エンチャント：`nEnch(o)`（一括は `askNEnchAll()`）
  - 部隊の動き：`data-mode`（guard 迎撃・hold 固守・return 帰還）
  - 作るもの：精錬所 `data-smode`、火薬工房 `data-pmode`
  - 魔核の守り石：詳しい欄の `#iWard`（中身は `wardPut(o)`。一括は `askWardAll()`）。**今は詳しい欄の下のほうにあり、スクロールしないと見えない**。ユーザーの指定（2026-11-20）：今は動かさず、**この作り直しで半円のボタンとして出す**
  - 兵を作る：`data-model`（育てられる兵は `modelsAt(type,b)`）
- **襲撃中（夜）も同じ操作**。補給・装備など夜にできないものは灰色にして理由を出す。

### 2-4. 「見る」で詳しい欄
- 半円の「見る」を押すと、**詳しい欄をマップに重ねて出す**（PC：右から、スマホ：下から）。閉じるとマップが全部見える。
- 中身は今の詳しい欄（`renderInfo()`）と同じでよい。

### 2-5. 一括・依頼・研究・記録など
- 今の下のボタンの役目（一括 `bulkMenu()`、依頼 `showOrders()`、研究 `showResearch()`、記録、速さ、一時停止、設定）は、マップの上の小さなボタンから開けるようにする。どこに置くかは試しながら決める。

## 3. 進め方（案）

1. **切り替えの設定を作る**：しばらくは「新しい操作／前の操作」を設定で切り替えられるようにして、比べながら直す。
2. **マップを広げる・下のボタンを重ねる・建設ボタンと一覧**。
3. **半円のボタン**（施設・部隊。はみ出すときは画面を寄せる。灰色のボタンの理由）。
4. **「見る」の詳しい欄を重ねて出す・スマホとタブレットの調整**（横持ち `body.land`・縦持ちの両方）。
5. チュートリアル（書記官リリアのミッション・`LIL_TIPS` の説明・`tools/rec_tut2.js` で録った動画）が、新しい操作で合わなくなるところを直す。
