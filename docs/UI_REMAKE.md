## 1. 今の画面と、困っていること

**今の画面（PC）**
- 左：マップ（`#left` > `#mapWrap` > `#cv`）
- 右：選んだものの詳しい欄（`#right` > `#info` / `#infoBody`）と、タブ（`#rtabs`：建設 `#build`・研究・軍事 `#armyBox`・街 `#econ`）
- 上：日付・襲撃までの日数（`#wave`）、1日の長さのバー（`#rtBar`）、資源の欄（`#resbar`）
- 下：ボタン（`#controls`：夜へ `#bNext`・速さ `#bSpd`・一時停止 `#bPause`・一括 `#bBulk`・依頼 `#bOrd`・記録 `#bHist` など）と通信ログ（`#log`）
- スマホは右の欄が下からの引き出し（`#sheetHandle`）になる。置く場所の決定は `#bpad`（`#bpOk` 建てる／`#bpCancel` やめる）

**困っていること（ユーザーの言葉から）**
1. 右と下のメニューが場所をとって、**マップが小さい**。
2. 詳しい欄をよく見ないと、**何ができるかが分からない**。仕組みを知っている人でないと、**エンチャント・強化（アップグレード）・装備には絶対に気づかない**。
3. スマホ・タブレットでの操作もよくしたい。

## 2. 目指す形（決まったこと）

### 2-1. マップを画面いっぱいに
- 右の欄（`#right`）は常には出さない。マップ（`#cv`）を画面いっぱいにする。
- 上の資源の欄と日付・1日のバーは、**細い1段**にまとめてマップの上に置く。
- 下のボタンは、**マップの上に重ねた小さなボタン**にする。**「夜へ」だけは大きく、右下**。
- 通信ログは、必要なときに開く形（小さくたたむ）。

### 2-2. 建設ボタン → 一覧 → 置く場所を決める
- マップの**右下（夜へのとなり）に「建設」ボタン**を重ねて置く。
- 押すと、**建物の一覧**が出る（防衛・領地・部隊のタブ。アイコン・名前・費用。今の `renderBuild()` の中身と同じ情報）。
- 選ぶと**置く場所を決める状態**になる（今の `enterBuild(type)` と同じ）。
  - PC：今までどおりクリックで置く。数字キー（Shift＋数字キー）で選ぶのもそのまま使えるように。
  - スマホ：指で置く場所を動かして、「ここに建てる」「やめる」で決める（今の `#bpad` を使う）。

### 2-3. 押した物の上に「半円のボタン」
施設や部隊を押すと、**その上に半円の形でボタンが並ぶ**。ここから操作する。

- ボタンは**アイコン＋名前**。指で押しやすい大きさ（目安 44px 以上）。
- **まだ使えないものも灰色で出して、押すと理由を出す**（例：「研究『防衛のエンチャント付与』で使えます」「襲撃の日に使えます」）。これで、エンチャントや装備があること自体に気づけるようにする。
- **押した物がマップの上の端などにあって、半円が画面からはみ出すときは、画面（カメラ）が動いて、押した物の上に半円が出せる位置まで寄せる**（ユーザーの指定。半円を下向きにするのではなく、画面のほうを動かす）。
- 何もない所を押すか、もう一度押すと閉じる。

**出すボタン（案。並びや中身はユーザーと決めながら）**

| 押したもの | ボタン |
|---|---|
| 施設（防衛） | 見る・強化（アップグレード）・改造・エンチャント・**魔核の守り石**（魔法の研究「魔核の守り石」のあと）・修理・解体 |
| 施設（生産） | 見る・強化（道具を替える／アップグレード）・作るもの（精錬所・火薬工房など、選べるものだけ）・エンチャント・修理・解体 |
| 施設（兵の施設：兵舎・馬小屋（大きな厩舎）・錬金工房・蒸気の工場・兵器工房） | 見る・兵を作る・強化・修理・解体 |
| 城 | 見る・城の強化・研究・依頼 |
| 部隊 | 見る・迎撃・固守・帰還・補給・装備・エンチャント |
| 何部隊かをまとめて選んだとき | まとめて迎撃・固守・帰還・補給 |

- 今の詳しい欄（`renderInfo()`）の中にあるボタンを、半円から呼ぶ：
  - 修理 `#iRep`、解体 `#iDemo`、アップグレード `#iUpg`（城の強化は `#iBaseUp`）、補給 `#iSup`
  - 改造：`modBlock(o)` の中のボタン（`data-mod`）→ `setMod(type,id)`
  - エンチャント：`nEnch(o)`（一括は `askNEnchAll()`）
  - 部隊の動き：`data-mode`（guard 迎撃・hold 固守・return 帰還）
  - 作るもの：精錬所 `data-smode`、火薬工房 `data-pmode`
  - 魔核の守り石：詳しい欄の `#iWard`（中身は `wardPut(o)`。一括は `askWardAll()`）。**今は詳しい欄の下のほうにあり、スクロールしないと見えない**。ユーザーの指定（2026-11-20）：今は動かさず、**この作り直しで半円のボタンとして出す**
  - 兵を作る：`data-model`（育てられる兵は `modelsAt(type,b)`）
- **襲撃中（夜）も同じ操作**。補給・装備など夜にできないものは灰色にして理由を出す。

### 2-4. 「見る」で詳しい欄
- 半円の「見る」を押すと、**詳しい欄をマップに重ねて出す**（PC：右から、スマホ：下から）。閉じるとマップが全部見える。
- 中身は今の詳しい欄（`renderInfo()`）と同じでよい。

### 2-5. 一括・依頼・研究・記録など
- 今の下のボタンの役目（一括 `bulkMenu()`、依頼 `showOrders()`、研究 `showResearch()`、記録、速さ、一時停止、設定）は、マップの上の小さなボタンから開けるようにする。どこに置くかは試しながら決める。

## 5. 進み具合（試作版に入れたもの）

### 1回目（2026-11-20）：切り替え・マップを画面いっぱい・建設ボタン
- **切り替え**：`setUI2(on)`。`body.ui2` と `body.fullmap`（前からある全画面の作り）をつける。ブラウザの全画面にはしない。覚える場所は `localStorage` の `nd_ui2`（`'1'`／`'0'`。**何もなければ新しい操作**）。下のボタンの `#bUI2`「前の操作にする／新しい操作（試し）」で切り替え。前の操作のときは今までどおり。
- **右下**：`#bNext`（夜へ）を大きく、そのとなりに `#u2Build`（建設）。建設を押すと `#right` が開いて建設のタブ（もう一度押すと閉じる）。建物を選ぶと（`enterBuild`）閉じて、置く場所を決める状態に。
- 右の欄が開いている間は、夜へ・建設のボタンが欄の左へずれる（`:has(#right.open)`）。右の欄は日付の段の下（`top:110px`）から。
- 置く建物の帯（`#modeBar`）が全画面のときに大きく広がっていた不具合を直した（左上の細い1段に）。
- **スマホ縦**（幅900px以下）は、下の帯（夜へ・建設・研究・軍事・その他）がもうあるので、重ねるボタンは出さない（4回目で調整）。

### 2回目（2026-11-20）：押した物の上に半円のボタン
- 施設・部隊・城・まとめて選んだ部隊（`S.multi`）を押すと、その上に半円のボタン（`#u2Ring`）。毎フレーム `u2Tick()` が位置を合わせる（部隊が動いてもついていく）。
- **右の欄は選んだだけでは開かない**（`openSheet()` も新しい操作では止める）。「見る」で開く。土地や英雄を選んだときは今までどおり開く（`u2Sel()`）。
- **押した物が画面の端にあって半円がはみ出すとき**は、画面（カメラ）が少しすべって、半円が見えるところまで寄る（`u2Fit()`。上の段・日付の段・選択中の帯の下まで）。マップの端でそれ以上動けないときは、そのまま。
- ボタンは アイコン＋名前（60×52px）。**まだ使えないものは灰色**で、押すと理由がトーストで出る（例：「研究『防衛のエンチャント付与』で使えます」「壊れていません」）。今の状態のもの（例：今の動き「迎撃」）は明るい色。
- 中身は、今の詳しい欄（`renderInfo()`）のボタンを呼ぶ（動きは前の操作と同じ）。**1つだけ押すもの**（強化 `#iUpg`・城の強化 `#iBaseUp`・エンチャント `#iNE`・守り石 `#iWard`・修理 `#iRep`・解体 `#iDemo`）はそのまま押す。**選ぶもの**（改造・作るもの・兵を作る・装備）は詳しい欄を開いて、その場所までスクロールして光らせる（`u2Look(sel)`）。

| 押したもの | 半円のボタン（左から） |
|---|---|
| 施設 | 見る・強化・改造（改造のある施設）・作るもの（精錬所・火薬工房の2段目から）・訓練（兵の施設）・エンチャント（つけられる施設）・守り石（防衛施設）・修理・解体（建設中は「取り消し」） |
| 城 | 見る・城の強化・研究・依頼・訓練 |
| 部隊 | 見る・迎撃・固守・帰還・補給・装備・エンチャント |
| まとめて選んだ部隊 | まとめて迎撃・まとめて固守・まとめて帰還・まとめて補給 |

- 並び順と数の多いときの出し方は、**とりあえずこちらで決めた**（上の表。数が多いと半円が大きくなる）。ユーザーに見てもらって直す。

- 並び順は、ユーザーが見て「いい」と言った（2026-11-20）。

### 3回目（2026-11-20）：詳しい欄の出し方・スマホとタブレット
- **マップを本当に画面いっぱいに**：新しい操作では、地図（`#cv`）を画面のいちばん上から出す（`resizeView()` の `isFull()` の中、`body.ui2` のとき `top=0`）。上の段・日付の段・選択中の帯はマップに重ねる。上の段の真下にある物は押せないので、そのときは画面を動かす。
- **スマホの横持ち**（`body.land`。右に縦の帯：夜へ・建設・研究・軍事・街・その他）：前は地図が高さ200pxしかなく、下が黒く空いていた → 右の帯のぶんだけ空けて、あとは全部地図に。
  - **スマホの縦持ちは「横にしてください」と出る作り**（`body.needRotate`・`#rotateMsg`）。なので、スマホは横持ちだけ考えればよい。タブレットは縦も横もある。
- **右の欄の中身を、開き方で分けた**（PC・タブレット横。`#right` に `u2sel`／`u2tab`）：
  - 半円の「見る」で開いたとき（`u2sel`）：選んだものの詳しい欄（`#info`）だけ。タブや建設の一覧は出さない。
  - 「建設」「研究」「軍事」「街」で開いたとき（`u2tab`）：タブと中身だけ（選択中の欄は出さない）。タブの右端の × で閉じる（`#u2X`）。同じボタンをもう一度押しても閉じる。
- **PCの下のボタンに「研究」「軍事」「街」**（`#u2Tabs`。`u2Tab(t)`）。右の欄が開いているときは、夜へ・建設のボタンが1段上にずれる（下のボタンが2段に折り返さないように）。
- **タブレット縦**：閉じているときの下の引き出し（「▲ 詳細・建設」）を隠した（「見る」と下の帯の「建設」で開く）。スマホ横・タブレット縦の「見る」は今までどおり引き出し（タブ付き）で開く。選ぶのをやめると閉じる。

### 4回目（2026-11-20）：ユーザーの感想から
- **半円の「解体」**：前は1回押しても見た目が変わらず（詳しい欄の中だけ確認の表示になっていた）、分かりにくかった → 1回目でボタンが赤く光る「もう一度で解体」に変わり、戻る資源をトーストで出す。3秒以内にもう一度押すと解体。
- **「強化」「エンチャント」は確認画面を出してから**（`u2AskUpg(o)`・`u2AskEnch(o)`・共通の `u2Ask()`）：

  - 数字：**今 → あと**を矢印で並べ、良くなるほうを**緑の文字**に（中身は `kcStat(o)`。城は詳しい欄の「レベルが上がると：」の文）。

### 5回目（2026-11-20）：選んだ物へ寄る・戻る
- **選ぶと拡大**（ユーザー案）：施設・部隊・城・まとめて選んだ部隊を押すと、「キュイ」という音（効果音 `zoomin`）がして、その物へ寄って拡大する（`U2_ZOOM`＝1.8。物は真ん中より少し下に置き、上に半円が出るように。`u2ZoomTo`・`u2CamTo`・アニメは `u2ZoomStep`）。拡大し終わったあと、半円がはみ出すときは今までどおり少し寄せる（`u2Fit`）
- **半円のいちばん右に「戻る」**：選ぶのをやめて、選ぶ前の画角に戻る（音 `zoomout`「キュウ」。`u2Back`）。続けてほかの物を選んでも、戻るのは最初の画角（`U2R.home`）。「戻る」を押さずに閉じたら（何もない所を押す・もう一度押す）、今の画角のまま
