# 宣伝用の素材（ver 1.4 時点）

売り：資材を集める施設を建てながら、同時に防衛もしないといけない。大量に押し寄せる敵をどう凌ぐかを考えるのが醍醐味。
キャッチコピー：**昼に築き、夜に凌げ。**

## 動画の流れ（35秒）
1. キービジュアル「昼に築き、夜に凌げ。」
2. 昼：街が育っていく（資材を集め、街を築く）
3. 日が暮れて、闇から大群が迫る
4. 北の城壁で激突（城壁と防衛施設で迎え撃て）
5. 引いて全体（四方から来る大群を、どう凌ぐか）
6. 東の壁へ（街づくり×タワーディフェンス）
7. ロゴ・ブラウザで無料プレイ・URL

画面はすべて実際のゲーム（ver 1.4・グレイヴェル平原）。研究を全部済ませて城Lv5にした街に、約270体の魔物を3方向から出して撮影。城は無傷のまま守りきっている。曲は `tools/music.py` で作ったもの。

## 作り直し方（`tools/`）
Playwright・ffmpeg・Python（Pillow・numpy）と DotGothic16 フォントが必要。スクリプト内の作業フォルダのパスは書き換えて使う。
1. `node rec.js` … ゲームを開いて街を作り（`town.js`）、大群を出し（`raid.js`）、1コマずつ撮る（仮想の時計で30fps）
2. `python3 stills.py` … 静止画
3. `python3 music.py` … 曲
4. `python3 compose.py` → `ffmpeg -framerate 30 -i vframes/v%05d.jpg -i music.wav ...` … 字幕を重ねて動画に

## 第2版（v2）：築く・凌ぐ・攻める

- 構成：オープニング → ①築く（街が育つ）→ ②凌ぐ（夜の大群と城壁の攻防）→ ③攻める（駐留地への夜襲）→ エンドカード。38.5秒。
- 街の配置を2案で撮影：
  - `v2/mixed/` 案A 混ぜて詰める（家・畑・工房を城から順にぎっしり）
  - `v2/zoned/` 案B まとめる（北東に住宅・南に畑・西に工房）
- 各フォルダに動画（720p）と画像4枚（16:9・正方形・縦長・特徴カード）。
- 撮影用スクリプトは `tools/`。`LAYOUT=mixed|zoned node rec.js`、`node recsiege.js`、`python3 compose.py <案>`、`python3 music.py`、`python3 stills.py <案>`。撮影時だけ施設の上限を外しています（ゲーム本体は変更なし）。
