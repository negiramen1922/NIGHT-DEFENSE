# 研究の整理ボード（2つ目・今使っているもの）

claude.ai の Artifact https://claude.ai/artifact/K4cx9jLcpKJ7hrQAf1HawE （オーナーだけが開ける）の元。2026-11-18 から、試作版の今の中身から自動で作っている。
カードを動かす・線をつなぐ・研究を足す・メモは Artifact の db（`notes`・`pos`・`links`・`custom`）に入るので、ArtifactData で読める。

作り直し（スクラッチの作業フォルダで）：
1. `node dump.js`（試作版から研究・城のランクで開くもの・道具とアップグレードの段・装備を `rb/proto_dump.json` に書き出す。中のパスは作業フォルダに合わせる）
2. `python3 mk_actual.py`（`data.json` の「領地・防衛・部隊」タブを作り直す。`data_base.json` を `data.json` として使う。「前：生産」などのタブはもとの研究）
3. `head.html` ＋ `body.html`（`__DATA__` に data.json）で `research_board.html` を作り、同じ Artifact に publish

**並びを保つ**：`fix.json`（カードid → タブ・列・行）に前の並びを入れておくと、作り直してもそのカードは同じ場所に出る（新しいカードは空いているところへ）。カードを足したり消したりして並びが変わると、ユーザーがボードで動かしたカードとずれるので、必ず `fix.json` を残したまま作り直す。新しいカードの場所も残したいときは、作ったボードの位置を読み直して `fix.json` に足す

**方針（2026-11-20）**：カードごとに 共通・工業・魔法 を選べる（db の `line` コレクション、doc id はカードid、`{ln:'共'|'工'|'魔'}`）。選んでいないカードはゲームの今の振り分け（`TECH_LINE`）。「素材」タブ（`N素材`）は mk_actual.py で作る。素材のカードの並びは fix.json の `res_*`

**方針ごとの並び（2026-11-20）**：「方針ごとに分けて並べる」ボタン（はじめから入）で、共通・工業・魔法の帯に分け、帯の中を前提の木の形に並べる（保存した位置は使わない。カードを動かすときは切る）。カードを選ぶと、その前提と先のカードの線が光り、ほかは薄くなる。mk_actual.py の `QA` は工業・魔法の案のカード（prop「案」）
- `newicons.json`：エーテル金属（水色）と黒鉄のインゴットのアイコン（mk_actual.py が読む）
